# DevPulse ⚡ — Creative Developer Portfolio

**DevPulse** is a visually stunning, fully animated interactive developer portfolio designed to showcase software projects, engineering craftsmanship, and live repository telemetry in style. 

Built with **TanStack Start**, **React**, **TypeScript**, and **Tailwind CSS**, DevPulse blends high-performance web engineering with rich visual animations and fluid UI interactions.

## ✨ Visual & Interactive Features

- 🎭 **Rich Canvas & Smooth Motion**: Fluid transitions, cursor-aware elements, ambient background glows, and interactive particle fields.
- ⚡ **Interactive Project Showcases**: Interactive 3D/hover card effects highlighting software architecture, live demos, and technical features.
- 📊 **Animated Telemetry & Stats**: Animated counters for live commit activity, total contributions, pull requests, and repository stars.
- 🎨 **Theme & Visual Modes**: High-contrast dark aesthetics with neon ambient accents, grain overlays, and custom glassmorphism design.
- 📜 **Timeline Journey**: Animated career, education, and milestone timeline with scroll-triggered animations.
- 📱 **60 FPS Performance**: Optimized GPU-accelerated motion designed to run smoothly on mobile and desktop.

## 🚀 Quick Start

### Prerequisites

Ensure you have **Node.js** (v18.18+ or v20+) installed. We recommend using [nvm](https://github.com/nvm-sh/nvm):

```bash
nvm use 20

```
### Clone the repository

```bash
git clone [https://github.com/your-username/devpulse.git](https://github.com/your-username/devpulse.git)
cd devpulse
npm install
npm install
```
Open http://localhost:3000 in your browser.


## 🛠️ Tech & Motion Stack
- Framework: TanStack Start (Full-stack SSR React framework)

- Language: TypeScript

- Styling: Tailwind CSS

- Animation & FX: Framer Motion / Motion, Canvas API, Lucide Icons

- UI Components: Custom Glassmorphism UI & Radix Primitives
